# Internationalization

init({ locale: "de" }) — German editor chrome and block defaults.

Contract: https://docs.templatical.com/guide/i18n
Live: https://play.templatical.com/scenes/i18n

## Snippet

```ts
import { init } from "@templatical/editor";
import "@templatical/editor/style.css";

const editor = await init({
  container: document.getElementById("editor"),
  locale: "de",
});
```
