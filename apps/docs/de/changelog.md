# Changelog

Die Release-Notes von Templatical werden **auf Englisch** veröffentlicht. Sie entstehen
aus den Changesets der einzelnen Pull Requests, und eine Übersetzung würde
unvermeidlich hinter den Releases zurückbleiben — deshalb pflegen wir bewusst nur
eine Fassung.

[**Zum vollständigen Changelog**](/changelog)

Dort finden Sie für jede Version die enthaltenen Änderungen, das Release-Datum und
die Pakete, die die jeweilige Änderung betrifft.

## Weitere Quellen

- [GitHub Releases](https://github.com/templatical/sdk/releases) — eine Release-Notiz
  pro Version, abonnierbar über den Atom-Feed
  (`https://github.com/templatical/sdk/releases.atom`) oder über
  _Watch → Custom → Releases_ auf GitHub.
- [Installation](/de/getting-started/installation) — Upgrade auf die aktuelle Version.

## Versionierung

Alle `@templatical/*`-Pakete teilen sich **eine Versionsnummer** und werden gemeinsam
veröffentlicht. Ein Eintrag im Changelog nennt daher die Pakete, die er tatsächlich
verändert — die übrigen erhalten dieselbe Version, ohne inhaltliche Änderung.
