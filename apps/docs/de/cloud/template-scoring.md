# Template-Prüfungen (zukünftig)

Dies ist ein Platzhalter für zukünftige Cloud-Funktionen. Clouds KI erscheint in einer späteren Version. Für KI heute verwenden Sie [Ihren eigenen AI-Provider](/de/backend/ai).

Für deterministische Inhaltsprüfungen stehen [Zustellbarkeit](/de/quality/deliverability/) und [Kompatibilität](/de/quality/compatibility/) zur Verfügung. Diese Prüfungen sagen keine Postfachplatzierung voraus.
